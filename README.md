# Pedagogica-local-AI-Assistant
«Локальный педагогический ИИ помощник» — приложение, которое основывается на работе генеративной модели искусственного интеллекта. Этот инструмент призван решить множество педагогических задач. Подойдет всем, кто вовлечен в образовательный процесс.

Особенности приложения:
1. 100% Локально и приватно: работает автономно: все вычисления происходят на компьютере пользователя без интернета. Все данные лекций или рефератов студентов и личная информация не уходит в сеть.
2. Возможность задать генеративной модели любую задачу, например, составить план семинара или лекции, придумать практические задания для обучающихся, сгенерировать билеты или проверить документ.3
3. Поддержка файлов.docx`, `.pdf`, `.xlsx и `.md. Для этого просто перетащите мышкой файл прямо в окно программы, и ИИ выполнит задачу строго по вашему материалу.
4. Оптимизирован под слабые ПК: для запуска и работы достаточно процессора с поддержкой инструкций AVX и 8 ГБ оперативной памяти.

---

Как скачать и запустить программу?

Для этого вам не нужно быть разработчиком и разбираться в коде! Я сжал и упаковал всё приложение вместе с ИИ-моделью в один удобный установщик:

1. Зайдите в раздел **Releases** в правой части этой страницы и скачайте файл **`PedagogicalAssistant_Setup.exe`** 
2. Запустите скачанный файл и установите программу, следуя подсказкам (как обычный софт).
3. Кликните по ярлыку на Рабочем столе — откроется красивое графическое окно, и ассистент готов к работе!
